# المراجع — كل مفتاح مستعمل في هذا المستودع

**القاعدة:** كل رقم في `docs/` أو `data/` يحمل مفتاحًا من هذا الجدول، أو اسم السكريبت الذي
أنتجه. المفتاح = اسم المؤلف الأول (بحروف صغيرة) + السنة.

**عمود «التحقّق»** يعني بالضبط ما قرأناه:

| الرمز | معناه |
|---|---|
| `crossref` | البيانات الوصفية (المؤلفون، المجلة، الصفحات، السنة) مقروءة من Crossref API |
| `abstract` | الملخّص مقروء كاملًا (Europe PMC أو ناشر مفتوح) |
| `fulltext` | النص الكامل مقروء |
| `UNVERIFIED` | لم نتمكّن من قراءته — لا يُقتبس منه رقم |

آخر تحقّق شامل: **2026-10-07**.
