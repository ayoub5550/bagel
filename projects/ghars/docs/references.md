# المراجع — مشروع تمر الغرس

نفس قاعدة المستودع: المفتاح = اسم المؤلف الأول (بحروف صغيرة) + السنة.
عمود «التحقّق» له نفس معاني [`docs/references.md`](../../../docs/references.md) في الجذر:
- `crossref`: البيانات الوصفية؛
- `abstract`: الملخّص؛
- `fulltext`: النص الكامل؛
- `openalex`: السجلّ فقط، بلا DOI؛
- `UNVERIFIED`: لم نقرأه.

آخر تحقّق: **2026-10-07**.
