# bagel — مشروع الباقل (*Anabasis articulata*)

بحث مفتوح: **هل في نبتة الباقل الصحراوية شيء ذو قيمة حقيقية؟** جزيء دوائي، مادة صناعية، أو
منتج قابل للبيع — وما أرخص طريقة لإثباته أو نفيه.

الطريقة: **مختبر جاف (in-silico)** — مسح آلي للأدبيات، جرد مركّبات موثّق، حساب الخصائص الدوائية،
بحث عن أهداف بيولوجية في ChEMBL، ومحاكاة ارتباط (docking) مع ضابط موجب.
